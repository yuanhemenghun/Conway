# 根据原论文 arxiv 2049.20341v1 实现一下部分证明过程

## 证明了什么及证明思路

fst.py文件用于证明任何符合“连续字符不超过3个且仅由1、2、2、d”组成的“一日字符串”，以某个位置为分裂点左右分别迭代，把分裂点左右字符相同称为耦合，如果8次迭代后仍然未耦合，则字符串可以在此分裂（无穷次迭代后仍不会耦合）。

转换器 exlarge_audio 检查一个插入分裂符的“一日字符串”的分裂符左右的字符是否相同，如果相同，说明不能在此分裂，拒绝，否则在保留分裂符的同时输出两侧字符串经过一次迭代的结果。而 sink 接受一个字符串并输出一个空字符串，或者输入一个拒绝标志(None)然后也拒绝。因此 sink(exlarge_audio<sup>n</sup>) 识别一个插入分裂符的“一日字符串”是否耦合，或这个字符串经过 n-1 次迭代之后结果是否耦合，耦合则拒绝，否则输出空字符串。

这意味着每个 sink(exlarge_audio<sup>n</sup>), n in N<sup>+</sup> 都接受一些满足特定规则的字符串，并拒绝其他的。如果存在某个m，使 sink(exlarge_audio<sup>m</sup>) 和 sink(exlarge_audio<sup>m+1</sup>) 两个转换器的结构完全相同，则说明一个字符串如果能被 sink(exlarge_audio<sup>m</sup>) 接受，那它也一定能被 sink(exlarge_audio<sup>m+1</sup>) 接受。由于 sink 只是把 exlarge_audio<sup>n</sup> 的输出串转成空字符串，把拒绝信息保留，所以能被 sink(exlarge_audio<sup>n</sup>) 接受的字符串也是能被 exlarge_audio<sup>n</sup> 接受的字符串，所以上面的结论可以变为“一个字符串如果能被 exlarge_audio<sup>m</sup> 接受，那它也一定能被 exlarge_audio<sup>m+1</sup> 接受”（注意 exlarge_audio<sup>m</sup> 和 exlarge_audio<sup>m+1</sup> 的结构并不一定相同，因为它们有输出，不只负责识别合法性）。

设能通过 exlarge_audio<sup>m</sup> 的合法性检查的字符串集合为 L，则它同时也是 exlarge_audio<sup>m+1</sup> 的合法字符串集，由于 exlarge_audio<sup>m+1</sup> = exlarge_audio(exlarge_audio<sup>m</sup>)，说明 L 即使再经过一次 exlarge_audio，也不会有任何子集被拒绝，因此可以归纳出 L 经过无穷次 exlarge_audio 也仍然不会收窄。这证明了一旦一个字符串经过 m-1 次 exlarge_audio 迭代而分裂符左右仍不同，则它经过无穷次迭代也不会耦合，即可在分裂符两侧裂变。

程序计算了 sink(exlarge_audio<sup>1~10</sup>)，发现 sink(exlarge_audio<sup>9</sup>) 和 sink(exlarge_audio<sup>10</sup>) 结构相同，因此可证开头的结论。

“符合特定规则的字符串集合”也可以说是一种“语言”，所以也可以用类似的方法判断两种语言是否相同。

## 计算康威常数

有了这个结论，就可以通过8次游程编码迭代判断任意一个一日字符串是否可以在某个位置分裂。非一日字符串，会在有限次迭代内变成一日字符串，在变成一日字符串之前，字符串长度随迭代指数级下降。

进而可以将任意一个字符串分裂为原子，或它不可分裂，本身就是原子。

当一个字符串被分裂为不同的原子，意味着它无论迭代多少次，都只是各个原子单独迭代，所以之后的迭代中再裂变出新的原子，也只能是从某一个原子的迭代中分裂出来的。

因此，可以从任何一个数字开始，先分裂成原子，然后对各个原子单独迭代一次，把迭代后的字符串分裂成新原子，记录 原子->新原子列表 的映射，再迭代，再分裂，再记录；如果遇到已经出现过的原子就跳过。由于迭代到一定次数之后原子数量不再增加（宇宙学定理，在论文中也是通过构造另一个“原子分裂转换器”E 并程序证明 E<sub>24</sub>=E<sub>25</sub> 来说明的，不过这里没实现），这个过程一定会终止。然后移除这个映射图中所有不在环内的原子，因为这些原子不会在无穷次迭代后继续循环出现。有了这个映射，就可以通过 https://www.bilibili.com/video/BV1bzuU6VEGX/ 提供的方法计算康威常数。

上面描述的构建映射的这几步过程比较简单，只需基础图论知识，所以也懒得写代码了。
